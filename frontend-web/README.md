# ZoPic Studio - Portail Photographes (Web)

Cette application React/Vite est destinée aux **photographes professionnels**.
C'est un tableau de bord SaaS complet permettant de :
- Créer et gérer des compétitions et épreuves.
- Uploader des lots de photos.
- Suivre les statistiques de ventes.

## Démarrage Rapide

```bash
npm install
npm run dev
```

## Structure
- `src/components/` : Composants UI réutilisables (Design System).
- `src/pages/` : Vues principales (Dashboard, Competitions, Upload).
- `src/services/` : Appels API vers le backend (`/api/v1`).

Pour plus d'informations sur l'architecture globale, voir le dossier `/docs` à la racine.
