PARTIE 1 — VISION
1. PRÉSENTATION GÉNÉRALE
1.1 Résumé Exécutif
ZoPic Studio est une plateforme unique qui connecte les photographes sportifs aux participants. Elle permet à un photographe de publier ses photos d'événement, à l'intelligence artificielle d'indexer automatiquement les visages, et aux sportifs de retrouver leurs photos par simple selfie et de les acheter via le paiement mobile money.

La plateforme intègre également un espace de stockage cloud avec galeries privées, épreuvage client et watermarking automatique, accessible via abonnement.

1.2 La Promesse du MVP
Un photographe publie un événement. Un participant prend un selfie, retrouve toutes ses photos en quelques secondes, et les achète avec Wave ou Orange Money.

1.3 Un Produit, Deux Applications
ZoPic Studio se décline en deux applications distinctes partageant le même backend :

Application	Public	Plateformes	Usage principal
ZoPic Photographe	Photographes professionnels	Mobile (Flutter) + Web (React/Vite)	Upload, gestion, stockage, suivi des ventes
ZoPic Photos	Sportifs, parents, clients finaux	Mobile (Flutter) + Web (React/Vite)	Recherche par selfie, achat, téléchargement
Les deux applications partagent un backend unique en architecture monolithe modulaire, avec extraction progressive en microservices si la charge l'exige.

10.2 Architecture Logicielle : Monolithe Modulaire
Pour le MVP, un seul projet FastAPI organisé en modules indépendants. Chaque module est auto-contenu avec son router, service et repository. Communication inter-modules via services, pas via imports directs. Cette architecture permet une extraction progressive en microservices si la charge l'exige.

Principes :

Un seul projet, un seul déploiement.

Organisation en modules indépendants.

Chaque module est auto-contenu.

Communication inter-modules via des appels de service.

Base de données partagée mais accédée module par module.

Stratégie d'évolution :

Extraction progressive de certains modules en microservices.

Modules prioritaires : reconnaissance faciale (CPU-intensif), stockage (fort volume), paiements (isolation de sécurité).

Observabilité	Prometheus + Grafana + Loki	Métriques, logs, traces
Justification des choix principaux :

Flutter : Performance native supérieure, meilleur pour les flux caméra et les galeries d'images performantes.

FastAPI : Écosystème IA natif en Python, stack unifiée pour l'API et les workers IA.

InsightFace + Qdrant : Souveraineté des données, pas de coût par requête, conformité locale.

Cloudflare R2 : Zéro frais de transfert, tarification prévisible.

14.3 Résilience
Backoff exponentiel : délai croissant en cas d'échec.

Dead Letter Queue (DLQ) : après 3 échecs, inspection manuelle.

Recyclage workers IA : max_jobs=500, redémarrage automatique.

Verrouillage transactionnel : SELECT FOR UPDATE SKIP LOCKED pour rétrocessions.

Indexation Qdrant en batch : un seul appel groupé par photo.

Type	Protection

Originaux (HD)	Bucket R2 privé, Object Lock, MFA Delete, chiffrement
Photos livrées	Watermark invisible (DWT), URL signée 24h, 3 téléchargements max, empreintes SHA-256 et pHash
Watermark invisible :

Utilise la transformation en ondelettes discrètes (DWT).

Intègre l'identifiant de l'acheteur dans l'image.

Permet la traçabilité en cas de fuite.

15.3 Sécurité des Paiements
Service isolé du reste de l'application.

Idempotence garantie par contrainte unique.

Machine à états stricte.

Reconciliation toutes les 15 minutes.

Verrou transactionnel PostgreSQL.

Jeux de test conservés et diversifiés (ethnie, âge, luminosité).

17. CONFORMITÉ ET PROTECTION DES DONNÉES BIOMÉTRIQUES
17.1 Principes
Consentement explicite : case à cocher avant toute analyse faciale.

Extraction seule : seuls les vecteurs mathématiques sont stockés.

Suppression immédiate : le selfie est supprimé juste après extraction.

Collections éphémères : suppression automatique 30 jours après l'événement.

Pas de croisement : chaque événement a sa propre collection Qdrant isolée.

Chiffrement : AES-256 au repos, clés gérées avec rotation.

17.2 Droits des Utilisateurs
Droit d'accès : consulter ses données.

Droit de rectification : modifier les informations de profil.

Droit à l'effacement : bouton "Supprimer mes données faciales", effacement sous 24h avec preuve.

Droit à la portabilité : export des données sur demande.

17.3 Conformité Réglementaire
Déclaration à la Commission des Données Personnelles (CDP) du Sénégal.

Conformité avec la Loi n°2008-12 sur la protection des données personnelles.

Audit externe annuel du système biométrique.

Journalisation de tous les accès aux données faciales.
